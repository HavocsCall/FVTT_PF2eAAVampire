# PF2e AA: Vampire

A custom Vampire ancestry module for PF2e on Foundry VTT.

## Requirements

- PF2e AA Library (`FVTT_Pf2eAALibrary`)

## Current Scope

- Vampire ancestry and six Vampire heritages
- Vampire ancestry and heritage feats, features, and actions
- Hunger meter registration and Vampire-specific condition/rest automation
- Shared former-ancestry and meter behavior supplied by PF2e AA Library

The module is in early alpha.
