## [0.3.0] - 2026-10-06

### Changed

- Renamed the module to PF2e AA: Vampire with module ID `FVTT_Pf2eAAVampire`
- Moved shared former-ancestry and meter code to PF2e AA Library

## [0.2.0] - 2026-07-02

### Added

- Former ancestry sync support for the Vampire ancestry, including expanded chassis syncing and built-in former ancestry selection support
- Vampire hunger tracking panel for vampire player characters
- Hunger automation for threshold-based condition syncing and Rest for the Night increases
- World settings for hunger tracking behavior, rest-based hunger increases, and default hunger thresholds

### Changed

- Reorganized the module scripts into longer-term ancestry and hunger feature folders
- Cleaned up localization so only actively used keys remain in the language file
